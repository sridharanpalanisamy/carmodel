# Self-hosted 360° vehicle videos

Place one **model-specific, licensed turntable video** in this folder for each vehicle.
The homepage checks these local MP4 files first and uses the matching interactive 3D
model only as a fallback while a video is unavailable.

## Video requirements
- MP4 container, H.264 video, AAC audio optional (muted by default).
- 1920x1080 or 1440x1080, 24–30 fps, 6–15 seconds, seamless loop.
- A full, unobstructed 360° exterior rotation of the exact vehicle/model year.
- Stable camera, consistent lighting, vehicle centered, no titles or watermarks.
- Prefer 8–20 MB per clip for GitHub Pages; optimize with H.264 CRF 22–25.
- Only add footage with a license that permits redistribution and the intended use.
  Record the creator, source URL, license, and any attribution in `CREDITS.md`.

**Important:** No video files are included yet. We found web references to Ford turntable footage,
but they are not all downloadable, model-accurate, or clearly licensed for redistribution.
Do not copy YouTube/Vimeo/stock previews into this repository without permission.
