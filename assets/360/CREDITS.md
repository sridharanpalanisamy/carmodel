# Self-hosted 360° showroom credits and rights

The 360° selector lists all 11 vehicles in this project. The viewer code is local and does not use third-party embedded viewers.

## Current media status

No 360° vehicle videos or 3D model files have been added yet. All 11 vehicle entries are pending their own exact-model local assets. Do not describe the showroom as fully operational until each file has been added and tested.

For every future asset, record:
- Exact vehicle and model year / variant
- Local filename
- Creator / renderer
- Original source of any 3D asset used
- License or written permission allowing modification, rendering and website use
- Required attribution and modifications
- Date rights were checked

Do not add footage unless it depicts the exact vehicle and the rights permit its intended use. No third-party viewer should be reintroduced as a fallback.
